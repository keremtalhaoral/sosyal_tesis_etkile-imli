⚡ EXPLAIN ANALYZE — B-Tree ve GiST İndeks Performansı

213.000 rezervasyon ve mekansal tesis tablosunda indeksli arama sorgu planı:

EXPLAIN ANALYZE SELECT f.id, f.ad, ST_Distance(f.geom::geography, ST_SetSRID(ST_MakePoint(28.976, 41.037), 4326)::geography) AS mesafe_metre FROM facilities f ORDER BY f.geom::geography <-> ST_SetSRID(ST_MakePoint(28.976, 41.037), 4326)::geography LIMIT 3;
→ Index Scan using idx_facilities_geog on facilities
  Order By: (geom::geography <-> 'POINT(28.976 41.037)')
  Planning Time: 0.124 ms
  Execution Time: 0.842 ms (Seq Scan: 14.8 ms - 17.5x hızlanma)
