🏛️ PostGIS Mekansal Tablo Tanımı (DDL)

CREATE EXTENSION IF NOT EXISTS postgis; -- Tesisler Tablosu: Koordinat ve PostGIS geometry(Point, 4326) CREATE TABLE facilities ( id INTEGER PRIMARY KEY, kod VARCHAR(16) UNIQUE NOT NULL, ad VARCHAR(128) NOT NULL, lat DOUBLE PRECISION NOT NULL, lng DOUBLE PRECISION NOT NULL, capacity INTEGER NOT NULL CHECK (capacity > 0), geom geometry(Point, 4326) GENERATED ALWAYS AS ( ST_SetSRID(ST_MakePoint(lng, lat), 4326) ) STORED ); -- Mekansal GiST İndeksi: KNN ve Mekansal Aramaları O(log N) yapar CREATE INDEX idx_facilities_geom ON facilities USING GIST (geom); CREATE INDEX idx_facilities_geog ON facilities USING GIST ((geom::geography));

📐 Mekansal Join Sorgusu (Point-in-Polygon)

-- Tesisin hangi ilçe poligonu içinde olduğunu PostGIS ile bulma SELECT f.ad AS tesis_adi, d.name AS ilce_adi FROM facilities f JOIN districts d ON ST_Contains(d.geom, f.geom) LIMIT 5;

💡 1. Hafta Kazanım Özeti

  • Normalizasyon (1NF - 3NF): İlişkisel veri modelleme ve yabancı anahtar kısıtları (FK Cascade) kurgulandı.
  • Spatial ETL: Ham İBB verisindeki koordinat hataları düzeltilerek WGS84 formatına dönüştürüldü.
  • QGIS & PostGIS: Overpass Turbo ile aktarılan 39 ilçe poligonu ile tesis noktaları çakıştırıldı.
